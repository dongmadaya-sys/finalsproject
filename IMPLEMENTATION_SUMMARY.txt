================================================================================
API FUNCTIONS
================================================================================

showAlert(title, message, options = {})
├─ title: string
├─ message: string (supports \n for line breaks)
└─ options: object
   ├─ onOk: function → Callback when OK clicked
   ├─ onDismiss: function → Callback when Dismiss clicked
   ├─ autoClose: boolean → Auto-close alert (default: false)
   └─ autoCloseDelay: number → Delay in ms (default: 5000)

closeAlert()
└─ Closes the current alert

showNoiseAlert()
└─ Shows the noise level warning (your requirement)

COMMON USAGE PATTERNS
================================================================================

1. Show and Auto-Dismiss
   showAlert('Info', 'Processing...', {
     autoClose: true,
     autoCloseDelay: 3000
   });

2. Confirmation Dialog
   showAlert('Confirm', 'Continue?', {
     onOk: () => { /* do action */ closeAlert(); },
     onDismiss: () => closeAlert()
   });

3. Error Notification
   showAlert('Error', 'Something went wrong', {
     autoClose: true,
     autoCloseDelay: 7000
   });

4. Noise Detection
   if (noiseLevel > 65) {
     showNoiseAlert();
   }
