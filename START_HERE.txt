💻 CORE FUNCTIONS REFERENCE
─────────────────────────────────────────────────────────────────────────────

showNoiseAlert()
  Shows the exact noise alert from your requirements
  Title: ⚠️ High Noise Level Detected
  Message: High Noise level detected in this area. Kindly lower your voice to respect others
  Usage: showNoiseAlert();

showAlert(title, message, options)
  Shows a custom alert with your content
  Params:
    - title: string (alert title)
    - message: string (alert message, supports \n for line breaks)
    - options: object with:
      - onOk: function (callback when OK clicked)
      - onDismiss: function (callback when Dismiss clicked)
      - autoClose: boolean (auto-close after delay)
      - autoCloseDelay: number (milliseconds, default 5000)
  Usage: showAlert('Title', 'Message', { onOk: () => closeAlert() });

closeAlert()
  Closes the currently displayed alert
  Usage: closeAlert();

🎯 COMMON USE CASES
─────────────────────────────────────────────────────────────────────────────

Show Noise Alert:
  showNoiseAlert();

Show Custom Alert:
  showAlert('Warning', 'Your message here');

Alert with Action:
  showAlert('Confirm', 'Proceed?', {
    onOk: () => { /* do something */ closeAlert(); }
  });

Auto-Closing Alert:
  showAlert('Done', 'Success!', {
    autoClose: true,
    autoCloseDelay: 3000
  });

Error Alert:
  showAlert('❌ Error', 'Something went wrong', {
    autoClose: true,
    autoCloseDelay: 5000
  });

Integrate with Noise Detection:
  if (noiseLevel > 65) {
    showNoiseAlert();
  }
