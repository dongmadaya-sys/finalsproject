
## 💡 Common Use Cases

### Alert when noise is high
```javascript
if (noiseLevel > 65) {
  showNoiseAlert();
}
```

### Alert with callback
```javascript
showAlert('Title', 'Message', {
  onOk: () => {
    console.log('User clicked OK');
    closeAlert();
  }
});
```

### Auto-closing alert
```javascript
showAlert('Done!', 'Operation successful', {
  autoClose: true,
  autoCloseDelay: 3000  // 3 seconds
});
```
